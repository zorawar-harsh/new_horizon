# Eco-Reform — Climate-Resilient Adaptive Prisons

> **TYCIA Foundation's flagship climate-resilience programme transforming custodial facilities into climate-adaptive, sustainable, and rehabilitative spaces.**

Piloted at **Nuh District Jail, Haryana**, in institutional partnership with the **Department of Prisons, Haryana**, and supported by the **Rainmatter Foundation (Zerodha)**.

---

## Overview

Prisons house dense populations in hardened concrete environments subject to extreme temperatures, severe water stress, and structural resource limitations. Project Eco-Reform addresses these compounding vulnerabilities through 30 targeted custodial interventions:

- **Thermal Resilience**: High-albedo solar-reflective cool-roofing coatings, bamboo window lattices, and passive thermo-siphonic cross-ventilation louvers lowering barrack temperatures by **3.5°C to 5.2°C**.
- **Water Conservation**: Multi-stage rooftop rainwater catchment harvesting **~450,000 liters** per monsoon, push-timed aerators reducing tap consumption by 42%, and deep percolation aquifer recharge shafts.
- **Waste Circularity & Soil Health**: Central mess 3-stream segregation and aerobic vermicomposting pits processing **250 kg/day** of kitchen scraps into 1.5 tons of nutrient-rich bio-fertilizer monthly.
- **Restorative Living & Nutrition**: A **1.2-acre permaculture garden** yielding over 420 kg of chemical-free vegetables per crop cycle.
- **Accredited Livelihoods**: Certified custodial training in agroecology, nursery management, and environmental maintenance linked to post-release employment pipelines.

## Getting Started

### Prerequisites

- Node.js >= 20.x
- npm >= 10.x (or Bun / pnpm)

### Installation

```bash
# Clone the repository
git clone https://github.com/zorawar-harsh/new_horizon.git
cd new_horizon

# Install dependencies
npm install

# Start local development server (runs on http://localhost:8080)
npm run dev
```

### Production Build

```bash
# Generate optimized production build
npm run build

# Preview production build locally
npm run preview
```
